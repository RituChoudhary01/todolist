# Todo List
A simple and interactive Todo List web application built with HTML, CSS, and JavaScript.<hr>

# Features
Add tasks to the list<br>
Remove tasks with a delete button<br>
Mark tasks as completed by clicking on them<br>
User-friendly interface<br>

# Technologies Used
HTML<br>
CSS<br>
JavaScript<br>
Font Awesome (for icons)<br>
